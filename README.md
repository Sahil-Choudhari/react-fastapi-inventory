# react-fastapi-inventory

# Inventory Management System

## 🚀 Tech Stack
- Frontend: React
- Backend: FastAPI
- Database: MySQL / SQLite

## 📌 Features
- Add products
- View product list
- Update product details
- Delete products

## ▶️ How to Run

### Backend
cd backend
pip install -r requirements.txt
uvicorn main:app --reload

### Frontend
cd frontend
npm install
npm start
